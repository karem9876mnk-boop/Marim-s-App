# Study App (PWA)

Open the GitHub Pages link on your phone, then use the browser menu -> "Install app" / "Add to Home screen".

**API key:** it is NOT stored in the code. The app asks for your Gemini key (AIza...) the first time you press Process,
and saves it only on that device. Use the green key button to change it.
Create a key at https://aistudio.google.com/apikey
